# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.1] - 2026-05-04

### Added

- Platform-specific keyboard shortcuts for improved accessibility.
- Collapsible "Recent Connections" section in the sidebar.
- Official Lunar branding/logos in the "About" panel and "Welcome" view.
- Folder suggestion dropdown and tagging support in the Connection Form.

### Changed

- UI now automatically synchronizes with the active terminal theme for a more cohesive look.
- Improved window title bar styling and behavior.
- Standardized project formatting using Prettier.

### Fixed

- Resolved an issue where modal containers would interfere with window dragging.
- Fixed a bug causing multiple IPC handler registrations for window minimization.
- Updated updater error messages for better clarity.

### Removed

- Solarized Dark theme.
- Legacy distribution build scripts.

## [1.0.0] - 2026-05-04

### Added

- Cross-platform builds for macOS, Windows, and Linux.

## [0.0.1] - 2026-04-25

### Added

- First implementation of Lunar.
