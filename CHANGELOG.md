# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-04-30

### Added

- SSH terminal with full xterm.js integration (WebGL rendering, search, web links).
- SFTP file manager with drag-and-drop upload/download support.
- Connection manager with encrypted credential storage (SQLite).
- Multi-tab terminal sessions with split pane support.
- Dark/light theme toggle with system preference detection.
- Command palette for quick navigation and actions.
- Cross-platform builds for macOS, Windows, and Linux.
- Auto-update support via `electron-updater`.

## [0.0.1] - 2026-04-25

### Added

- First implementation of lunar.
